# Change Spec（需求总规格）

> 阶段：sdd-prd 产物（多 Story Change 级）
> 输入：`requirement.md`、`exploration.md`

## 0. 元信息

- Change ID: CHG-0008
- Requirement: REQ-M1-002
- 状态流转: exploring → specified

## 1. 背景

统一认证只能证明调用者是谁，不能证明其有权执行后台操作。商品、库存、订单和系统配置等后续模块需要一致的 RBAC 能力，避免各服务通过角色名称或 Java `if/else` 重复实现权限。该 Change 在 CHG-0007 身份基础上建立权限数据、管理 API、运行时授权、缓存失效和审计闭环。

## 2. 用户价值

- 目标用户: 超级管理员、权限管理员、后台业务管理员、受保护业务服务
- 痛点摘要: 缺少管理员和角色维护；菜单、按钮、API 权限没有统一模型；登录用户可能默认访问全部接口；权限变化缺少及时失效与审计。
- 预期价值: 权限管理员可配置最小权限，不同管理员获得差异化权限；业务服务以统一机制拒绝越权；敏感变更可追溯。

## 3. 功能范围

### 3.1 包含

- [S1] 查询、创建、修改、启用和禁用管理员，保护内置超级管理员不被误锁死。
- [S2] 查询、创建、修改、启用和禁用角色，角色编码唯一且稳定。
- [S3] 为管理员分配有效角色并以替换语义维护关系。
- [S4] 维护目录与页面菜单的父子关系、排序、路由元数据和启停状态。
- [S5] 维护按钮/操作与 API 权限资源，采用统一权限编码规则。
- [S6] 为角色分配菜单、操作和 API 权限，停用资源不再产生有效授权。
- [S7] 在业务服务通过 Spring Security 权限表达式真实校验 API 权限并返回 403。
- [S8] 在 Redis 缓存管理员权限快照，并在管理员、角色或授权关系变化时使旧快照失效。
- [S9] 记录管理员、角色、菜单权限和分配关系的关键变更审计。

### 3.2 不包含

- mall-admin 动态路由、菜单渲染和按钮隐藏（CHG-0009）。
- 商品、订单、库存等具体权限清单和资源所有权规则。
- 商城会员授权模型。
- 通用日志检索、审计报表和审计长期归档平台。
- ABAC、组织架构权限、数据行列级权限和临时授权审批。

## 4. 业务规则总纲

- 最小权限：已认证不等于已授权；除明确的超级管理员策略外，不存在“登录即拥有全部权限”。
- 稳定编码：角色和权限编码创建后不可静默改变语义；权限编码采用 `<resource>:<action>` 小写格式并保证唯一。
- 有效关系：禁用管理员、禁用角色、禁用菜单或权限资源均不产生有效授权。
- 分配原子性：管理员角色和角色权限采用完整替换或明确增删的事务语义，失败不得留下部分关系。
- 后端边界：每个受保护 API 声明所需 Permission Code；前端是否展示入口不影响后端判定。
- 缓存一致性：权限快照带版本；变更成功提交后使受影响管理员版本失效，下一次读取重建，不能长期继续使用旧权限。
- 安全治理：关键变更记录操作者、对象、动作、变更前后摘要、结果、时间和 traceId，敏感值脱敏。
- 防锁死：系统必须保留至少一个可用超级管理员，禁止删除或禁用最后一个有效超级管理员。

## 5. 全局验收标准

- [ ] 管理员、角色、菜单、权限资源均可按范围维护，唯一性、层级和状态规则生效。
- [ ] 管理员角色与角色权限可事务化分配，不合法关系被拒绝。
- [ ] 不同角色得到不同有效权限集合，禁用节点不再授权。
- [ ] 有权限 API 通过，无权限管理员即使直接调用也稳定返回 403。
- [ ] Redis 权限缓存可命中；授权或状态变化后旧快照及时失效并重建。
- [ ] 禁用管理员不能继续正常访问受保护资源。
- [ ] 关键权限操作形成完整、脱敏、关联 traceId 的审计记录。
- [ ] 自动化测试覆盖 CRUD、关系分配、越权、缓存失效、防锁死和审计。

## 6. 非功能需求

- 安全：默认拒绝；管理 API 均要求明确权限；防止水平越权、批量分配注入和最后超级管理员锁死。
- 性能：缓存命中时单次权限集合读取 P95 低于 30ms；权限变更到新授权生效目标不超过 5 秒。
- 一致性：数据库是授权事实源，Redis 仅作可重建缓存；事务提交前不得发布失效结果。
- 可审计性：所有安全敏感变更具备不可由普通业务接口修改的审计记录。
- 可扩展性：后续业务模块只需登记 Permission Code 并声明后端校验点即可接入。

## 7. 成功指标

- RBAC 核心自动化用例通过率 100%，越权直调受保护 API 的阻断率 100%。
- 缓存命中时权限读取 P95 低于 30ms，权限变更后 5 秒内观察到新权限版本。
- 关键权限变更审计覆盖率 100%，无操作者、对象、结果或 traceId 缺失记录。
